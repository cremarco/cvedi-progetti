Il mondo delle api

Le nostre piccole amiche, seppur di dimensioni ridotte, hanno un grande ruolo all’interno del mondo della biodiversità. Grazie all’impollinazione le api contribuiscono a circa l’80% del cibo che mangiamo tutti i giorni. Le nostre amiche hanno un ruolo davvero decisivo nella catena alimentare

Senza le api

Con le api

Le api sono indicatori formidabili per le condizioni climatiche-ambientali. L’eccesso di pesticidi in agricoltura, l’inquinamento e l’aumento delle temperature stanno portando alla morte di questi insetti. I pesticidi e i fertilizzanti disorientano le api perché non depositandosi sui fiori non permettono di sentirne i profumi.

Senza le api

Con le api

Le api sono importanti anche per la nostra salute grazie al miele e la pappa reale. Infatti, questi prodotti contengono componenti utili al nostro corpo per prevenire o curare malattie come vitamine, sali minerali, zuccheri, enzimi e sostanze naturali ad azione antibiotica.

L'ape regina

L'ape regina è un individuo adulto, fertile, femminile della colonia d'api ed è normalmente la madre di tutte le api presenti nell'alveare. Di solito è l’unico individuo fertile in tutto l’alveare grazie alla pappa reale con cui viene nutrita per un lungo periodo di tempo.
